Headline findings

09 Mobile-Only Capabilities

Everything the apps do that the web cannot — the reason the apps exist.

Verified checkout end-to-end both

Address → pincode tier gating → fresh-tier slot picker → Razorpay with server-side HMAC verification (fail-closed) → confirmation with track-order.

Push notifications both

Order-stage pushes with foreground banners and tap-to-order routing; once-per-install permission ask, denial never blocks ordering.

Delivery Live Activity iOS

Lock-screen banner + Dynamic Island, ActivityKit push-driven updates, stage-tinted status icons.

Offline-first catalog both

Full catalog cached with ETag conditional refresh (304 extends freshness); iOS background-refresh task every 6 h; works airplane-mode.

OTP auth + token lifecycle both

Phone→OTP sign-in, single-flight token refresh (rotated refresh tokens), dead-session routing, full sign-out wipe.

Sign in with Apple iOS

SIWA beside the phone flow with shared credential funnel — an App Store requirement once any third-party login exists.

Saved addresses both

Server CRUD with default toggle, locally mirrored so the checkout picker never drifts.

Biometric lock both

Face ID / fingerprint gate on cold start when a session exists.

Order lifecycle UI both

List + detail with live-stage timeline across all 12 contract statuses, pull-to-refresh, friendly server-error mapping.

Deep links iOS

mishran://order/{id} and mishran://account with clean stack resets; unknown hosts ignored.

9-locale i18n with switcher both

Six locales beyond the web's three (ta/te/mr/gu/bn/pa) with instant in-app switching.

Loyalty pass display iOS

Wallet pass card in Account; Google Wallet parity deferred pending issuer setup.
