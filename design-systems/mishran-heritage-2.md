# Mishran Heritage 2

- Runtime id: `heritage-2`
- Source: Mishran menu top and bottom bars
- Mood: literary, ceremonial, warmer contrast, more overtly menu-led
- Canvas: parchment cream with source-matched wine red, saffron, and cocoa
- Best for: stronger header and footer chrome, premium menu storytelling, and brand moments that should feel closer to the printed menu

## Notes

- The primary wine red is sampled from the PDF menu bars and adapted directly for web use.
- This variant keeps the Mishran Heritage parchment base but makes the navigation and footer chrome feel closer to the printed menu.
- It works best when the header, footer, and primary call-to-action surfaces carry the stronger red while content sections still use warm neutrals.
