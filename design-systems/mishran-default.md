# Mishran Default

- Runtime id: `mishran-default`
- Source: Mishran Brand Strategy
- Mood: warm, milk-cream, kakvi-brown ink, festive saffron accent
- Canvas: soft milk-cream with deep brown text and a festive saffron accent
- Best for: canonical Mishran storefront — defaults, marketing landings, everyday shopping

## Core tokens

- Background (canvas): `#F7EFE0`
- Surface: `#FBF6EC`
- Primary / accent: `#9B4D2A` (kakvi brown)
- Pop / saffron: `#D79A35`
- Ink: `#2C1810`

## Notes

- This is the canonical Mishran identity theme and the default for first-time visitors.
- Pair with `Outfit` for sans display and serif fallbacks for editorial typography.
- Use as the baseline for accessibility contrast checks across the storefront.
