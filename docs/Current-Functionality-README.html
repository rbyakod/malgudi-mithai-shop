Stack

  • Next.js 16.2 App Router (TypeScript)
  • Payload CMS 3.87 + MongoDB adapter
  • MongoDB (Atlas M0 in prod, local mongod in dev)
  • next-intl 4.9 for locale routing (en / hi / kn)
  • Tailwind v4 via CSS variables for theming
  • Resend for transactional email (leads)
  • TanStack Query for client-side lead configurators
  • Sonner for toast notifications
  • Vercel for hosting (region bom1)

Brand & content system

14 Payload collections

What Content types editable in the Payload admin UI at /admin.

How Each collection is a TypeScript config under collections/. Payload bootstraps the admin UI, validates writes, and exposes a typed REST + GraphQL API automatically. afterChange and afterDelete hooks on each collection fire ISR purges.

Collections: mithai-products, qsr-menu-items, snack-products, merch-products, gift-boxes, stories, karigars, farms, packaging, occasions, leads, brand-settings (global), analytics-settings (global), wedding-leads + corporate-leads (sub-collections of leads).

5 Payload globals

What Site-wide settings editable without code deploys.

How Defined in globals/. Read at request time from server components.

Globals: brand-settings (name, tagline, positioning, contact), analytics-settings (GA4 ID, Meta Pixel ID, WhatsApp number), site-navigation, footer, wedding-configurator.

Seed script

What Sample content for every vertical + brand collections.

How npm run seed walks each collection and inserts sample records idempotently. Safe to re-run.

Editorial storefront

Brand home live

What The marketing front door at / (locale-prefixed: /en, /hi, /kn).

How app/[locale]/page.tsx composes BrandHero (cinematic headline + dual CTAs), VerticalPortals (4-up editorial row), Pillars (4 brand promises), Occasions, and editorial insets. Reads live from Payload brand-settings.

4 vertical portals live

What Hub landing pages for each vertical: /mithai, /qsr, /snacks, /merch.

How app/[locale]/<vertical>/page.tsx fetches the relevant Payload collection, renders a grid of product cards, links into PDPs.

Product detail pages (PDPs) live

What One PDP per product: /mithai/[slug], /qsr/[slug], /snacks/[slug], /merch/[slug].

How Server components, statically pre-rendered (SSG) via generateStaticParams, revalidated on Payload afterChange. Includes gallery, long description, quantity selector, JSON-LD Product schema.

Stories hub + pillar routes live

What /stories hub + 4 pillar filter routes: /stories/farms, /stories/karigars, /stories/karigari, /stories/journal.

How Static routes under route group (pillar) — not a dynamic [pillar] segment, to avoid collision with [slug]. Each pillar page filters the stories collection by pillar tag.

Wedding lead configurator live

What /weddings page with multi-step lead form (occasion, headcount, budget, packaging, message).

How components/ledger/WeddingConfigurator.tsx uses useActionState (React 19) + TanStack Query. Posts to /api/leads. Success fires lead_submitted analytics event + Sonner toast.

Corporate lead configurator live

What /corporate page with corporate gifting form (company, volume, occasion).

How Same pattern as wedding configurator. Submits to /api/leads with a source: "corporate" tag.

API layer

POST /api/leads live

What Receives wedding + corporate lead submissions. Sends an email via Resend to LEADS_INBOX.

How Pure-handler pattern: lib/leads-api.ts exports the typed handler; app/api/leads/route.ts is a one-line re-export. Validated by Vitest unit tests at tests/unit/leads.test.ts.

GET /api/drafts live

What Time-limited draft preview sessions for editors checking unpublished content.

How lib/drafts-api.ts issues a signed session cookie with TTL. app/api/drafts/[sessionId]/route.ts resolves the session.

GET /api/search live

What Parallel search across 5 Payload collections (mithai, qsr, snacks, merch, stories).

How Promise.all over 5 collection queries; returns ranked list with collection tag. Relevance ranking + faceted filters deferred to Phase 1.

POST /api/revalidate live

What On-demand ISR purge webhook called by Payload afterChange / afterDelete hooks.

How lib/revalidate-api.ts validates the x-revalidate-secret header against REVALIDATE_SECRET, then calls revalidatePath for each affected route. Routes mapped from collection slug via COLLECTION_ROUTES. Draft autosaves are skipped via req.context.

SEO

  • sitemap.xml — lists every locale route. Generated by app/sitemap.ts.
  • robots.txt — generated by app/robots.ts. Allows all, points at sitemap.
  • JSON-LD — Product on PDPs, Organization on home, BreadcrumbList on hub + PDP.
  • hreflang alternates — emitted per route for en, hi, kn.
  • Metadata API — title, description, open-graph tags per route via generateMetadata.

Analytics

  • GA4 + Meta Pixel bootstrapped via components/Analytics/AnalyticsScripts.tsx (uses next/script with afterInteractive).
  • track() helper at lib/analytics.ts — typed 14-event union. Fires to both GA4 + Meta Pixel.
  • Wired events: lead_submitted, add_to_cart, locale_changed, theme_changed, whatsapp_clicked, product_viewed.
  • IDs source: Payload analytics-settings global first; env-var fallback (NEXT_PUBLIC_GA4_ID, NEXT_PUBLIC_META_PIXEL_ID) for unreachable Payload.
  • Regression guard: Vitest test asserts ≥4 importers of track().

Internationalization (i18n)

  • Locales: en, hi (Hindi), kn (Kannada). Locale-prefixed routes (/en, /hi, /kn).
  • Library: next-intl 4.9.1. Messages in messages/{locale}.json.
  • Locale switcher: in SiteHeader, uses @/i18n/navigation Link (NOT next/link) to preserve routing.
  • Translation state:
    • English — complete.
    • Hindi — complete.
    • Kannada — partial. Pdp / Leads / Commerce namespaces have _todo_kn markers. Tracked in ledger; full pass is a content task.

Theming

  • 4 themes locked: mishran-default, diwali-saffron, wedding-heritage, everyday-sage.
  • Legacy aliases collapse: festive → diwali-saffron, heritage/heritage-2 → wedding-heritage, sage → everyday-sage, navy/mblue2/mindbox/coinbase/ibm/yoshida/myblue → mishran-default.
  • Implementation: data-theme attribute on <html> + CSS variables in globals.css. Theme init script in app/layout.tsx via next/script beforeInteractive to prevent FOUC.
  • Switcher: ThemeContext persists selection to localStorage key mithai-theme.

On-demand ISR

  • Default revalidate: 60s on detail pages (PDPs, stories).
  • Purge hooks: Payload afterChange + afterDelete fire on each collection config via collections/_revalidate-hook.ts.
  • Purge path: hook POSTs to /api/revalidate with x-revalidate-secret. The route validates, then revalidatePaths across all 3 locales.
  • Draft autosave skip: req.context carries draft-autosave flag; the hook bails early.
  • Gift-boxes: deliberately omitted from COLLECTION_ROUTES — purges fall through to a layout-level purge.

CI

GitHub Actions workflow at .github/workflows/ci.yml runs on every PR:

  • test job: lint → tsc → unit tests → build. Node 22.
  • e2e job: MongoDB 7 service container + Playwright + axe a11y assertions against 4 core routes.
  • lighthouse job: continue-on-error: true — LHCI is flaky in CI; baseline stabilizing.

Test coverage

  • 54 unit tests (Vitest) — pure-handler API tests, lib tests, component tests.
  • 29 E2E tests (Playwright) — golden paths across home, verticals, PDPs, configurators.
  • 4 axe a11y assertions — tests/e2e/a11y.spec.ts runs wcag2a + wcag2aa against 4 pages.
  • Lint + tsc clean on every commit (CI gate).
